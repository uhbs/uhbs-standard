# IEC 62443 Mapping for OT / ICS Profiles (Informative)

**Status:** Informative · not an IEC conformity assessment<br>
**Applies when:** TPS `class` is `ICS-SCADA`<br>
**UHBS target / review:** 5.0.0 · `uhqs-v5.0-critical-gate-diagnostic` · 2026-09-18

Pinned editions used here:

- [IEC 62443-2-1:2024](https://webstore.iec.ch/en/publication/62883), edition 2.0 — asset-owner security program
- [IEC 62443-3-2:2020](https://webstore.iec.ch/en/publication/30727), edition 1.0 — system-design risk assessment, zones/conduits, SL-T
- [IEC 62443-3-3:2013](https://webstore.iec.ch/en/publication/7033), edition 1.0 — system security requirements and capability levels
- [IEC 62443-4-1:2018](https://webstore.iec.ch/en/publication/33615), edition 1.0 — secure product-development lifecycle
- [IEC 62443-4-2:2019](https://webstore.iec.ch/en/publication/34421), edition 1.0 — component technical security requirements

| UHBS area | IEC 62443 concept | Notes |
| --- | --- | --- |
| Module A protocol fidelity (Modbus etc.) | FR 3 — System integrity / protocol correctness | Exact PDU / exception behavior |
| Module D egress / containment | FR 5 — Restricted data flow | Zone/conduit boundary for decoys |
| Air-gapped sandbox prerequisite | Zones & conduits | Decoys **MUST NOT** bridge OT zones |
| Module C telemetry | FR 6 — Timely response to events | SIEM-quality OT events |
| Module F static secrets / keys | FR 1 — Identification & authentication | No hardcoded engineering passwords |
| Evidence-backed assessment decision | 3-2 risk assessment / SL-T context | Asset owner sets risk and target security level; UHQS does not |

UHBS does **not** replace a full 62443 assessment; it provides a repeatable decoy
lab-evidence input for an OT security review. These concept-level mappings have
**medium confidence** and do not establish an SL-T, achieved SL, component
capability level, certification, or safe production placement. The asset owner,
integrator, and product supplier have distinct responsibilities across the series.
