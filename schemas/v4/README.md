# UHBS v4 schemas (frozen)

These JSON Schemas validate **historical UHBS 4.6.1** scorecards, evidence packs, and target profiles under the v4 scoring model. They are frozen for backward validation and must not be changed for v5 work.

Current (v5) schemas live in `schemas/` at the repository root. The CLI mirrors these copies under `src/uhbs_cli/schemas/v4/`.
